Foliora

Foliora is book shelf like 2D sheld where we want to organize books like we organize them in shelf.

In a Global Layout we have two main components
1. Menu (Fixed and flowing in bottom middle)
2. BookShelf

In book shelves therecould be multiple shelves. Initially there will be 4. User can add more shelves if he want by clicking the menu (Add New Shelf)

In each shelf there could be fixed sized shelf space where user can move books by drag and drop. One book can be placed from one shelf to another shelfes fixed positions.

Each book components has some properties:
1. Primary Color
2. Secondary Color
3. Book Name
4. Author
5. Shelf Number
6. Position
